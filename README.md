# Proyecto-Docentes
Desarrollo de gestión de docentes y horarios 
usuario super admin se puede crear desde register en el login, la conexion se logro en clever, por el hecho de que el proyecto esta en un entorno virtual, primero se activa el entorno virtual: myvenv23/Scripts/activate
luego se inicia la carpeta raiz: cd HorarioDocentes
para terminar se ejecuta el proyecto: python manage.py runserver
